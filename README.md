# Marina Petric

Computational political communication researcher. Ph.D., Media and Communication, Texas Tech University (2026).

I study how hostile and political content spreads across platforms in the United States and Brazil. I use network analysis, structural equation modeling, and large language models for text classification.

## Selected work

- **X vs. Bluesky, 2026 U.S. midterms.** Comparative network analysis of election discussion on both platforms. Also, LLM text classification. Classifying survey qualitative question with language models, with validation against human coding [repo](https://github.com/trufamaria/x-bluesky-midterm-networks)
  
- **Dissertation analysis in R.** Mediation and SEM models comparing the U.S. and Brazil. [repo](https://github.com/trufamaria/Dissertation-analysis-in-R/tree/main) 

  
- **Telegram data collection and analysis.** Channel data pipeline built on telegram-tracker. [repo](https://github.com/trufamaria/telegram.git)

- **LLM text classification.** Classifying Telegram channels with language models. Initial pass for validation agains human coding. [repo] (https://github.com/trufamaria/Telegram-Thematic-Network.git)
  
## Tools

Python, R (lavaan, ggplot2), NodeXL, Gephi, Telegram API, ATLAS.ti, Tableau
