# Marina Petric

Computational political communication researcher. Ph.D., Media and Communication, Texas Tech University (2026).

I study how hostile and political content spreads across platforms in the United States and Brazil. I use network analysis, structural equation modeling, and large language models for text classification.

## Selected work

- **X vs. Bluesky, 2026 U.S. midterms.** Comparative network analysis of election discussion on both platforms. [repo]
- **Telegram data collection and analysis.** Channel data pipeline built on telegram-tracker. [repo]
- **Dissertation analysis in R.** Mediation and SEM models comparing the U.S. and Brazil. [repo]
- **LLM text classification.** Classifying political and hostile content with language models, with validation against human coding. [repo]
  
## Tools

Python, R (lavaan, ggplot2), NodeXL, Gephi, Telegram API, ATLAS.ti, Tableau
